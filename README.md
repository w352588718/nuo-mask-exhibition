# 面·傩：傩面具数字档案

一个静态互动展览原型，包含粒子开场、面具观察、局部放大及二维分区拆解。三张图片来自既有研究标注图，浮雕及拆解为分析示意；图片及衍生作品公开发布前应核实授权和署名。

## 本地使用
使用新版浏览器打开 index.html，或者在此目录运行静态 HTTP 服务。无需构建或安装依赖。

## GitHub Pages
推送到 GitHub 后，在仓库 Settings → Pages 选择 Deploy from a branch，选择 main 分支和 / (root) 文件夹并保存。等待部署完成，访问 GitHub 显示的网址。项目使用相对路径，适配仓库子路径。

## 素材和参考
图片来自本地资料库已有标注图；具体来源与权利需根据原资料库逐项确认。网页设计参考 Neutra VDL 和 Awards Racing 的公开页面；此项目不含其原站代码或其图片。
